English Learning App（開発途中）
英単語学習の継続を支援するためのWebアプリです。
単語の登録・翻訳・復習を一体化し、「覚えるまでの流れ」をシンプルに管理できるよう設計しました。

開発背景・目的
英単語学習では「調べる・保存する・復習する」という行為が分断されており、継続的な学習が難しいという課題があります。
本アプリではこの課題に対し、単語登録から翻訳・保存・一覧確認までを一つの流れとして統合することを目的として開発しました。

機能
英単語の登録機能
DeepL APIによる自動翻訳
単語一覧の表示機能
登録データの保存・取得（SQLite）


工夫した点
1. 学習フローの一体化
単語入力 → 翻訳 → 保存 → 確認 までを1つのUI上で完結させ、
「調べるだけで終わる」状態を防ぐ設計にしました。
2. コンポーネント設計（React）
UIを以下のように分割し、保守性を意識しました。
InputField：単語入力・登録処理
NotebookPage：単語一覧表示
Header：画面全体のUI構造管理
また、各コンポーネントを独立させることで再利用性を高め、今後の機能追加（テスト機能・復習機能など）にも柔軟に対応できる構成としました。


システム構成・処理の流れ
ユーザーが単語を入力
Flask APIにリクエスト送信
DeepL APIで翻訳処理
SQLiteに単語と翻訳結果を保存
React側で一覧表示

使用技術
Frontend：React / JavaScript / CSS
Backend：Python / Flask
Database：SQLite
API：DeepL API
